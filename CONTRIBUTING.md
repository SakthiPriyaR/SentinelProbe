# Contributing to SentinelProbe

Thanks for your interest in contributing!

1. Fork the repository and create a feature branch.
2. Install dev dependencies: `cd src && poetry install --with dev`
3. Make your change and add tests under `src/sentinelprobe/tests/`.
4. Run the tests: `cd src && poetry run pytest`
5. Open a pull request describing what you changed and why.

Please be respectful and constructive in all discussions.
